# Project Instructions

- Do not describe BetaManuscript access with copy that combines exclusivity/privacy wording and beta-stage wording.
- Prefer "early access", "waitlist", or "launch" depending on context.
- Waitlist subscribers should be promised early access and a launch discount code.
- Use `@/shared/ui/Heading` for every semantic heading. Pass the required `level` prop instead of writing native `<h1>`–`<h6>` tags or page-specific heading typography; extend the shared component with a named size or tone when a new context is genuinely needed.
